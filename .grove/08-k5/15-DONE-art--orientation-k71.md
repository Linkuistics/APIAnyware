## Decisions (running log)

D1. Use the plan's two-view option for G11: call-layer concepts in
`g11-calls.puml`, then description and access in `g11-description.puml`.
Eleven concept boxes plus publication actors and access relations in one view
would crowd the reading order. This is an editorial choice, not a medium
limitation. Both views use the shared PlantUML style and link through the
same described operations; the page retains its existing prose walk.

D2. Keep alternative watch contracts conditional in labels and captions.
The overview does not choose one lifetime, callback schedule or access
mechanism for the invented header. Align G1 and G4's titles and captions with
the model's concept names, while retaining their distinct workflow and
release-sequence roles.

D3. The bounded adversarial review returned one actionable omission: G11a
did not visibly connect outcomes to returned release obligations. Re-read
against model.md's Release responsibility section and plan §10; replace the
hidden layout edge with that explicit relation and state it in the adjacent
caption. The qualifier `returned` preserves the distinction from input
consumption at entry. This is a local missing edge, not a redesign requiring
a second reviewer.

D4. Declined additional diagrams for the domain comparisons and glossary
lookups as an editorial judgement: the existing comparison/slot tables and
G4/G9 carry those relations, while G11 now carries the model overview. Neither
a contract prohibition nor an inability of the medium drove this choice.
